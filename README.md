# GRC & IT Audit Portfolio

Hands-on IT audit and GRC projects built around a single end-to-end engagement at **Northbridge Pay**, a fictional UK fintech. Each project produces real audit deliverables, maps to recognised frameworks, and includes **automation** of repeatable audit steps.

> ⚠️ Northbridge Pay is fictional. All data is synthetic. No real client, employer or training-provider material is used.

---

## 🏢 The Scenario: Northbridge Pay
- UK-based payments fintech, ~400 employees, regulated by the FCA
- Cloud-first: AWS (payments platform) and Microsoft 365 / Entra ID (corporate)
- Relies on critical third parties for card processing, KYC and customer support
- Board has commissioned an IT audit ahead of ISO 27001 certification and a SOC 2 Type II report
